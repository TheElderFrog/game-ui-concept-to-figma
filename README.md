# game-ui-concept-to-figma

游戏 UI 概念生成、透明切图、Figma 分层还原与后期优化技能。

- [技能入口](SKILL.md)
- [素材与坐标契约](references/asset-contract.md)
- [匿名工作流案例](references/workflow-examples.md)
- [PNG 检查器](scripts/audit_png.py)，需要 Python 与 Pillow。

将本仓库目录放入 Codex 的 skills 目录，并命名为 `game-ui-concept-to-figma`。使用 `$game-ui-concept-to-figma` 调用。实际修改 Figma 时需要连接 Figma 插件，并按技能说明加载对应 Figma 技能。

公开内容仅包含通用流程、抽象案例与检查代码，不包含项目素材和内部聊天来源。
